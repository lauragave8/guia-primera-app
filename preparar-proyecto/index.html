Cómo usarla en Claude

  1. Descarga el ZIP

    Guarda preparar-proyecto.zip en tu dispositivo.

  2. Carga y activa la skill

    En Claude, entra a Personalizar → Habilidades (Customize → Skills). Pulsa +, elige Create skill → Upload a skill y selecciona el ZIP. Después, actívala.

  3. Cuéntale tu idea

    Abre una conversación nueva y adapta el mensaje de abajo. Responde a las preguntas y revisa el resumen. Después de tu respuesta a la revisión final, la skill está preparada para entregar el documento completo con el que continuarás la construcción.

Si no ves Habilidades, revisa que ejecución de código y creación de archivos esté activada en Configuración → Capacidades (Settings → Capabilities). Consulta las instrucciones oficiales de Claude.
